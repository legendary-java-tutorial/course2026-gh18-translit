# translit

Переводит русский текст в латиницу по стандарту ISO 9 — одна латинская буква на каждую кириллическую. Пригодится, когда имя или название нужно записать латиницей без потерь: по ISO 9 текст можно перевести обратно.

```
$ npm start -- "Привет, жёлтый щенок"
Privet, žëltyj ŝenok
```

## Как запустить

Нужен Node.js 24.12 или новее.

```
npm install
npm start -- "Привет, жёлтый щенок"
npm test
```

Другие алфавиты — `npm start -- --list`, разовый перевод другим — `npm start -- --alphabet passport Привет`.

## Мой алфавит

В `translit.config.json` выбран `iso9`. Почему он: у паспортного «щ» — четыре буквы `shch`, а у ISO 9 — одна `ŝ`, и по тексту видно, какая была буква.
